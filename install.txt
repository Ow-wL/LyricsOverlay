  📋 생성된 requirements.txt 내용
   - PySide6: GUI 프레임워크 (코드에서 주력으로 사용)
   - winsdk: 윈도우 기본 OCR 엔진 사용을 위한 SDK
   - pywin32: 윈도우 API 제어 (win32gui, win32ui 등)
   - opencv-python & numpy: 이미지 처리 및 데이터 계산
   - mss & pygetwindow: 화면 캡처 및 윈도우 창 관리
   - keyboard: 단축키 입력을 위한 라이브러리
   - rapidfuzz: 가사 검색 결과의 유사도 계산
   - beautifulsoup4 & requests: 웹 가사 크롤링 및 네트워크 요청

# 파이썬 가상 환경 설정
python -m venv venv 

# CMD 
call venv\Scripts\activate

# PowerShell
call venv\Scripts\activate
.\venv\Scripts\activate

## 보안에러 발생 시 아래 명령 
Set-ExecutionPolicy -ExecutionPolicy RemoteSigned -Scope Process

# 비활성화 
deactivate

# 삭제
rmdir /s /q venv

# .exe 파일로 만들기
pip install pyinstaller
cd [프로젝트파일]
pyinstaller --onefile --noconsole --icon=icon.ico main.py
