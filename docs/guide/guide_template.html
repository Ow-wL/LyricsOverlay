1시작하기 전에

LyricsOverlay는 멜론 PC 플레이어 화면에 보이는 가사를 Windows 기본 OCR(글자 인식)로 읽어 오는 방식으로 동작합니다. 아래 환경이 필요합니다.

항목필요 사항
운영체제Windows 10 이상 (Windows 11 권장)
음악 플레이어멜론 PC 플레이어
한국어 OCRWindows에 한국어 언어 기능이 설치되어 있어야 합니다.
인터넷원본 가사를 검색해 OCR 오타를 바로잡을 때 사용합니다.
한국어 OCR 확인 방법 Windows 설정 → 시간 및 언어 → 언어 및 지역에서 한국어가 목록에 있는지 확인하세요. 한국어 Windows라면 보통 이미 설치되어 있습니다. 없다면 "언어 추가"로 한국어를 설치합니다.

2설치 및 실행

  1. 실행 파일 내려받기GitHub 릴리즈 페이지에서 LyricsOverlay.exe를 내려받아 원하는 폴더에 둡니다. 따로 설치할 필요는 없습니다.
  2. 실행하기LyricsOverlay.exe를 더블클릭합니다. 처음 실행할 때는 준비에 몇 초 정도 걸릴 수 있습니다.
  3. 보안 경고가 뜨면"Windows의 PC 보호" 창이 나타나면 추가 정보 → 실행을 누릅니다. 서명되지 않은 개인 제작 프로그램이라 표시되는 안내입니다.
소스 코드로 실행하기 Python 3.10 이상에서 pip install -r requirements.txt 후 python main.py로 실행할 수 있습니다. 자세한 내용은 저장소의 INSTALL.md를 참고하세요.

3빠른 시작

  1. 멜론에서 음악 재생멜론 PC 플레이어로 음악을 재생하고, 가사가 보이는 창을 띄워 둡니다.
  2. LyricsOverlay 실행제어판 창과 함께 화면 위에 가사 오버레이가 나타납니다. 멜론 창을 자동으로 찾아 가사를 읽기 시작합니다.
  3. 위치와 모양 맞추기설정 → 동작에서 고스트 모드를 잠시 끄고 "오버레이 위치 이동"을 켜면 오버레이를 원하는 곳으로 끌어 옮길 수 있습니다.
  4. 감상하기다시 고스트 모드를 켜면 오버레이가 클릭을 통과시켜, 게임이나 작업을 방해하지 않습니다.
멜론 창을 최소화하지 마세요 최소화된 창은 가사를 읽을 수 없습니다. 다른 창 뒤에 두거나, 고스트 모드로 멜론 창을 숨겨 두세요.

4화면 둘러보기

왼쪽 사이드바에서 페이지를 바꿀 수 있고, 사이드바 아래쪽 스위치로 다크 모드를 켜고 끌 수 있습니다.

대시보드

  • 감상 요약: 들은 노래 수, 감상 시간, 매칭된 가사 줄 수를 보여줍니다. 오른쪽 위에서 세션 / 오늘 / 이번 주 / 이번 달 기준을 고를 수 있습니다.
  • 지금 재생 중: 곡 제목, 가수, 현재 가사를 보여줍니다. 아래 버튼으로 이전 곡 · 재생/일시정지 · 다음 곡을 조작합니다.
  • 시스템 로그: 곡 감지, 가사 검색 결과, 설정 변경 같은 동작 기록입니다.

감상 기록 · 통계

감상 기록에는 지금까지 들은 곡이 최신순으로 쌓입니다. 통계에서는 일별 · 주별 · 월별 감상 횟수 그래프와 자주 들은 노래 · 가수 TOP 5를 볼 수 있고, "전체 보기"로 전체 순위를 확인할 수 있습니다.

5오버레이 사용하기

고스트 모드

고스트 모드를 켜면 오버레이가 마우스 클릭을 통과시켜, 오버레이 뒤에 있는 창을 그대로 클릭할 수 있습니다. F9로 언제든 켜고 끌 수 있습니다.

  • 켜짐: 클릭이 통과합니다. 기본 설정에서는 멜론 창도 투명하게 숨깁니다.
  • 꺼짐: 오버레이를 클릭할 수 있습니다. 위치 이동, 크기 조절, 재생 버튼을 쓸 때 끕니다.

위치 · 크기 바꾸기

설정 → 동작에서 고스트 모드를 끄고 "오버레이 위치 이동", "오버레이 크기 조절"을 켭니다. 오버레이를 끌어 옮기고, 오른쪽 아래 모서리를 끌어 크기를 바꿉니다. 끝나면 두 옵션을 끄고 고스트 모드를 다시 켜면 됩니다. 설정 → 외관의 슬라이더로 크기를 숫자로 맞출 수도 있습니다.

재생 버튼

고스트 모드가 꺼져 있을 때 오버레이에 마우스를 올리면 이전 곡 · 재생/일시정지 · 다음 곡 버튼이 나타납니다. 이 버튼이 필요 없다면 설정 → 동작 → 오버레이 재생 버튼을 끄세요.

곡 정보와 긴 가사

오버레이 위쪽에 곡 제목과 가수가 표시됩니다(설정 → 동작 → 곡 정보 표시). 가사가 길면 오버레이 크기는 그대로 두고 글자를 조금 줄이며, 그래도 넘치면 끝을 "…"로 줄여 보여줍니다.

6듀얼 모니터에서 쓰기

기본 설정에서는 고스트 모드를 켜면 멜론 창이 투명하게 숨겨집니다. 한쪽 모니터에 멜론을 띄워 두고 다른 쪽에 오버레이를 쓰는 등 멜론 창도 계속 보고 싶다면 아래 옵션을 끄세요.

이 옵션을 끄면 고스트 모드에서도 멜론 창은 평소처럼 보이고 조작할 수 있으며, 오버레이만 클릭을 통과시킵니다. 멜론 창이 다른 창에 가려져 있어도 가사는 계속 읽힙니다.

멜론 창은 항상 원래대로 돌아옵니다 프로그램을 종료하면 숨겨 두었던 멜론 창이 원래 상태로 돌아옵니다. 프로그램이 비정상 종료되더라도 다음에 실행할 때 자동으로 복구합니다.

7오버레이 꾸미기

  • 프리셋: 타일을 클릭하면 바로 적용됩니다. "현재 스타일 저장"으로 지금 모양을 나만의 프리셋으로 저장하고, 직접 만든 프리셋은 우클릭해 삭제할 수 있습니다.
  • 가져오기 / 내보내기: 프리셋을 JSON 파일로 저장해 다른 PC로 옮기거나 공유할 수 있습니다.
  • 세부 설정: 글꼴, 배경 불투명도, 글자 · 배경 · 외곽선 색상, 외곽선 두께, 오버레이 크기를 조절합니다. 위쪽 미리보기에 바로 반영됩니다.
  • 오버레이 표시: 오버레이를 잠시 숨기고 싶을 때 끕니다.

8단축키

단축키는 다른 프로그램을 쓰는 중에도 동작합니다. 설정 → 단축키에서 입력 칸을 클릭한 뒤 원하는 키 조합을 누르면 바뀝니다.

동작기본 단축키
고스트 모드 켜기 / 끄기F9
재생 / 일시정지F8
다음 곡Ctrl + Shift + →
이전 곡Ctrl + Shift + ←
프로그램 종료Ctrl + Alt + Q
글자 하나짜리 단축키는 등록되지 않습니다 Q나 Shift+Q처럼 타이핑과 겹치는 조합은 다른 프로그램에서 글을 쓸 때 실수로 실행될 수 있어 등록되지 않습니다. Ctrl이나 Alt를 섞어 지정하세요.

9데이터 저장 위치

감상 기록과 설정은 기본적으로 문서\LyricsOverlay 폴더에 저장됩니다.

파일내용
lyrics_stats.json감상 기록과 통계
overlay_settings.json오버레이 모양, 동작, 단축키 설정
overlay_styles.json스타일 프리셋

저장 위치는 설정 → 시스템 → 경로 변경에서 바꿀 수 있습니다. 이 폴더를 복사해 두면 감상 기록과 설정을 백업할 수 있습니다.

10문제 해결

가사가 표시되지 않거나 "가사를 기다리는 중…"에서 멈춰 있어요.
멜론이 실행 중이고 창이 최소화되어 있지 않은지 확인하세요. 가사를 읽는 영역은 멜론 창 안의 정해진 위치를 사용하므로, 멜론 창 크기나 Windows 화면 배율이 크게 다르면 인식이 잘 안 될 수 있습니다. 대시보드의 시스템 로그에서 곡 감지 여부를 확인할 수 있습니다.
가사에 오타가 섞여 나와요.
원본 가사를 찾지 못하면 OCR로 읽은 글자를 그대로 보여줍니다. 시스템 로그에 "검색 결과 없음"이나 "에러"가 있는지 확인하세요. 인터넷 연결 문제라면 잠시 후 자동으로 다시 검색합니다.
멜론 창이 안 보여요.
고스트 모드에서 멜론 창을 숨기는 기본 동작입니다. F9로 고스트 모드를 끄거나, 설정 → 동작 → 고스트 모드에서 멜론 창 숨기기를 끄면 다시 보입니다. 프로그램을 종료해도 원래대로 돌아옵니다.
오버레이를 옮기거나 버튼을 누를 수 없어요.
고스트 모드가 켜져 있으면 클릭이 통과합니다. F9로 고스트 모드를 끈 뒤 조작하세요. 옮기려면 "오버레이 위치 이동"도 켜야 합니다.
게임 중에 단축키가 먹지 않아요.
관리자 권한으로 실행된 게임 안에서는 일반 권한 프로그램의 단축키가 동작하지 않을 수 있습니다. 이 경우 LyricsOverlay도 마우스 우클릭 → "관리자 권한으로 실행"으로 켜 보세요.
재생 버튼이나 미디어 단축키가 멜론을 조작하지 않아요.
버튼은 Windows 미디어 키를 보냅니다. 다른 앱(브라우저 영상 등)이 미디어 키를 먼저 가져가면 그 앱이 반응할 수 있으니, 다른 재생 중인 앱을 멈추고 다시 시도하세요.
실행할 때 보안 경고가 떠요.
코드 서명이 없는 개인 제작 프로그램이라 표시됩니다. GitHub 릴리즈에서 내려받은 파일이 맞다면 추가 정보 → 실행을 누르세요.
