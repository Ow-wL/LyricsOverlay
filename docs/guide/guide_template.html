1시작하기 전에

LyricsOverlay는 멜론 창을 화면 캡처해 가사가 보이는 부분을 Windows 기본 OCR(글자 인식)로 읽고, 멜론 웹에서 가져온 원본 가사와 비교해 오타를 바로잡은 뒤 오버레이에 띄웁니다. 멜론과 연동되는 공식 프로그램이 아니라 화면에 보이는 글자를 읽는 방식이므로, 멜론 창에 가사가 표시되어 있어야 합니다.

항목필요 사항
운영체제Windows 10 이상 (Windows 11 권장)
음악 플레이어멜론 PC 플레이어
한국어 OCRWindows에 한국어 언어와 광학 문자 인식(OCR) 기능이 설치되어 있어야 합니다.
인터넷원본 가사 검색과 새 버전 확인에 씁니다. 연결이 없어도 OCR로 읽은 가사는 표시됩니다.
한국어 OCR 확인 방법 Windows 설정 → 시간 및 언어 → 언어 및 지역에서 한국어가 목록에 있는지 확인하세요. 한국어를 누르고 언어 옵션에 "광학 문자 인식"이 설치되어 있어야 합니다. 없으면 대시보드에 "OCR을 사용할 수 없어요"라는 안내가 나옵니다.

2설치와 업데이트

  1. 실행 파일 내려받기GitHub 릴리스 페이지에서 LyricsOverlay.exe를 내려받아 원하는 폴더에 둡니다. 설치 과정은 없습니다. 바탕 화면이나 문서 안처럼 쓰기 권한이 있는 폴더에 두어야 앱 안 업데이트가 동작합니다.
  2. 실행하기LyricsOverlay.exe를 더블클릭합니다. 실행 파일 안의 구성 요소를 푸는 데 몇 초가 걸릴 수 있습니다.
  3. 보안 경고가 뜨면"Windows의 PC 보호" 창이 나타나면 추가 정보 → 실행을 누릅니다. 코드 서명이 없는 개인 제작 프로그램이어서 표시되는 안내입니다.
1.1.0에서 올라오는 경우 1.1.0에는 업데이트 기능이 없으므로 이번 버전은 릴리스 페이지에서 직접 받아 기존 파일을 바꿔 주세요. 1.2.0부터는 새 버전이 나오면 앱에서 바로 업데이트할 수 있습니다(12장). 작업 표시줄에 예전 버전을 고정해 두었다면, 고정을 풀었다가 다시 고정하세요.
소스 코드로 실행하기 Python 3.10 이상에서 pip install -r requirements.txt 후 python main.py로 실행합니다. 빌드 방법은 저장소의 INSTALL.md를 참고하세요.

3처음 실행하기

처음 실행하면 대시보드 위쪽에 세 단계 시작 안내가 나옵니다. 단계를 실제로 마치면 체크 표시가 붙고, 세 단계를 모두 마치거나 안내 닫기를 누르면 감상 통계로 바뀝니다.

  1. 멜론에서 노래 틀기멜론 PC 플레이어로 음악을 재생하고, 가사가 보이는 상태로 창을 띄워 둡니다. 곡이 감지되면 1단계가 체크됩니다.
  2. 가사가 나오는지 확인오버레이에 가사가 나오면 2단계가 체크됩니다. 나오지 않으면 영역 지정을 눌러 멜론 창에서 가사가 보이는 곳을 직접 고릅니다(6장).
  3. 오버레이 자리 잡기위치·크기 조정을 눌러 오버레이를 보기 편한 곳으로 옮기고 완료를 누릅니다.
멜론 창을 최소화하지 마세요 최소화된 창은 캡처할 수 없어 가사를 읽지 못합니다. 다른 창 뒤에 두거나, 고스트 모드로 멜론 창을 숨겨 두세요. 최소화하면 대시보드에 "멜론 창이 최소화돼 있어요"가 표시됩니다.

4대시보드

왼쪽 사이드바에서 페이지를 바꾸고, 사이드바 아래 스위치로 다크 모드를 켜고 끕니다. 사이드바 아래에는 지금 재생 중인 곡이 앨범 커버와 함께 표시됩니다. 창 크기는 자유롭게 조절할 수 있습니다.

  • 감상 요약: 들은 노래, 감상 시간, 매칭된 가사 줄 수. 오른쪽 위에서 세션 · 오늘 · 이번 주 · 이번 달 기준을 고릅니다.
  • 지금 재생 중: 곡 제목, 가수, 현재 가사와 인식 상태를 보여 줍니다. 아래 버튼으로 이전 곡 · 재생/일시정지 · 다음 곡을 조작합니다.
  • 오버레이: 화면 표시, 클릭 통과(고스트 모드), 위치·크기 조정, 위치 초기화를 여기서 바로 합니다.
  • 최근 활동: 곡 감지, 가사 검색 결과 같은 동작 기록입니다. 창 높이가 낮으면 접힙니다.

인식 상태

가사가 왜 나오거나 나오지 않는지 색 점과 함께 알려 줍니다.

상태뜻과 할 일
● 가사를 인식하고 있어요정상입니다.
● 멜론을 찾고 있어요멜론이 실행 중이 아니거나 창이 보이지 않습니다.
● 멜론 창이 최소화돼 있어요창을 최소화하지 말고 다른 창 뒤에 두세요.
● 가사 인식 영역이 멜론 창을 벗어났어요멜론 창 크기나 화면 배율이 바뀌었습니다. 옆의 버튼으로 영역을 다시 지정하세요.
● 가사 영역에서 글자를 찾지 못했어요간주 중이거나 가사가 없는 곡일 수 있습니다. 계속되면 영역을 다시 지정하세요.
● OCR을 사용할 수 없어요한국어 OCR이 설치되어 있지 않습니다(1장).

5오버레이 사용하기

클릭 통과 (고스트 모드)

켜 두면 오버레이 위를 클릭해도 뒤에 있는 창이 눌립니다. 게임이나 작업 중에는 켜 두세요. F9, 대시보드, 트레이 메뉴 어디서 바꿔도 같은 설정이 바뀝니다. 기본 설정에서는 고스트 모드일 때 멜론 창도 투명하게 숨깁니다(7장).

위치 · 크기 조정

대시보드나 설정 → 동작의 위치·크기 조정을 누르면 오버레이에 점선 테두리가 생기고 잠시 클릭을 받을 수 있게 됩니다. 끌어서 옮기고 오른쪽 아래 모서리를 끌어 크기를 바꾼 뒤 완료(또는 Enter)를 누릅니다. 취소(또는 Esc)를 누르면 조정 전 위치와 크기로 돌아갑니다. 조정이 끝나면 클릭 통과 설정은 원래대로 돌아옵니다.

오버레이가 보이지 않을 때 모니터 구성이 바뀌어 오버레이가 화면 밖에 있으면, 프로그램을 켤 때 주 모니터 아래쪽 가운데로 옮깁니다. 켜 둔 상태에서는 대시보드의 오버레이가 안 보여요 (위치 초기화)를 누르세요.

재생 버튼과 곡 정보

재생 버튼은 클릭 통과가 꺼져 있을 때만 누를 수 있습니다. 필요 없으면 설정 → 동작 → 오버레이 재생 버튼을 끄세요. 곡 제목과 가수는 곡 정보 표시로 켜고 끕니다. 가사가 길면 오버레이 크기는 그대로 두고 글자를 줄이고, 그래도 넘치면 끝을 "…"로 줄입니다.

6가사 인식 영역 지정

기본 인식 영역은 화면 배율 100%의 멜론 기본 창을 기준으로 합니다. Windows 화면 배율이 125%·150%이거나 멜론 창 크기가 다르면 가사가 엉뚱하게 읽히거나 아예 읽히지 않을 수 있습니다. 이때 가사가 보이는 곳을 직접 지정하세요.

  1. 멜론 창 띄우기가사가 보이는 상태로 둡니다. 최소화되어 있으면 캡처할 수 없습니다.
  2. 영역 지정하기설정이나 대시보드 안내의 버튼을 누르면 멜론 창이 캡처되어 나타납니다.
  3. 드래그로 고르기현재 줄과 다음 줄이 모두 들어가고, 곡 제목이나 버튼은 빠지게 잡습니다.
  4. 이 영역 사용을 누르면 바로 적용됩니다. 기본값으로를 누르면 처음 영역으로 돌아갑니다.

7듀얼 모니터에서 쓰기

기본 설정에서는 고스트 모드를 켜면 멜론 창이 투명하게 숨겨집니다. 한쪽 모니터에 멜론을 띄워 두고 다른 쪽에 오버레이를 쓰는 것처럼 멜론 창도 계속 보고 싶다면 설정 → 동작 → 고스트 모드에서 멜론 창 숨기기를 끄세요.

멜론 창은 항상 원래대로 돌아옵니다 프로그램을 종료하면 숨겨 두었던 멜론 창이 원래 상태로 돌아옵니다. 프로그램이 비정상 종료되더라도 다음에 실행할 때 가장 먼저 복구합니다.

8오버레이 꾸미기

  • 스타일 프리셋: 타일을 누르면 바로 적용됩니다. 현재 스타일 저장으로 지금 모양을 내 프리셋으로 저장하고, 내 프리셋은 타일 오른쪽 위 ×로 지웁니다. 키보드로는 Tab으로 고른 뒤 Enter로 적용, Delete로 삭제합니다.
  • 가져오기 · 내보내기: 프리셋을 JSON 파일로 저장하거나 불러옵니다. 가져온 프리셋은 내 프리셋에 추가되고, 기본 프리셋은 덮어쓰지 않습니다.
  • 직접 조정: 글꼴(현재 글꼴 이름과 크기 표시), 글씨 · 외곽선 · 배경 색, 배경 불투명도(%), 외곽선 두께, 오버레이 너비와 높이(px).

9단축키

단축키는 다른 프로그램을 쓰는 중에도 동작합니다. 설정 → 단축키에서 입력 칸을 누르고 원하는 키 조합을 누르면 바뀝니다. 등록한 조합은 Lyrics Overlay가 차지하므로, 앱이 켜져 있는 동안 다른 프로그램에서는 그 키가 동작하지 않습니다. 다른 프로그램이 먼저 쓰고 있는 조합은 등록되지 않고 대시보드 최근 활동에 알려 줍니다.

동작기본 단축키
고스트 모드 켜기 / 끄기F9
재생 / 일시정지F8
다음 곡Ctrl + Shift + →
이전 곡Ctrl + Shift + ←
프로그램 종료Ctrl + Alt + Q
  • 입력 중 Esc는 취소, Backspace는 그 단축키를 해제합니다.
  • 다른 기능에 이미 지정된 조합이나 Q, Shift+Q처럼 타이핑과 겹치는 조합은 경고 후 원래 값으로 돌아갑니다.
  • 단축키 기본값으로를 누르면 위 표의 기본값으로 돌아갑니다.
  • 재생 관련 단축키와 버튼은 멜론 창에 직접 명령을 보내므로, 브라우저 영상 같은 다른 앱은 반응하지 않습니다. 멜론이 최소화돼 있어도 동작합니다.
  • 단축키를 누르고 있어도 한 번만 실행됩니다. 이전 곡은 곡을 3초 넘게 들은 뒤에 누르면 처음으로 되감기고, 곧이어 한 번 더 누르면 이전 곡으로 갑니다(멜론 동작).

10감상 기록과 통계

  • 검색: 제목이나 가수 일부를 입력하면 바로 걸러집니다.
  • 앨범 커버: 곡마다 멜론 앨범 커버를 보여 줍니다. 새로 듣는 곡은 가사를 찾을 때 함께 받습니다. 예전 기록의 커버는 설정 → 시스템 → 예전 기록 커버 채우기를 눌렀을 때만 하나씩 천천히 찾습니다. 멜론에 요청이 몰리지 않도록 한 번에 최근 곡 20곡까지만 찾고, 남은 곡은 10분 뒤에 다시 눌러 이어서 받습니다. 누르기 번거로우면 예전 기록 커버를 조금씩 자동으로 채우기를 켜세요. 멜론에서 곡을 듣는 동안 5분에 한 곡씩 찾습니다(그만큼 멜론으로 가는 요청이 늘어납니다). 커버를 못 찾은 곡은 색 타일로 표시됩니다. 받은 커버는 데이터 폴더의 covers에 저장됩니다.
  • 멜론에서 열기: 곡을 더블 클릭하면 브라우저에서 멜론 곡 페이지가 열립니다. 1.2.3 이전에 쌓인 기록처럼 곡 정보가 없으면 제목·가수로 멜론 검색 결과를 엽니다.
  • 삭제: Ctrl·Shift로 여러 곡을 고른 뒤 선택 삭제나 Delete. 지운 기록은 되돌릴 수 없으며, 누적 감상 시간과 가사 줄 수는 그대로 남습니다.
  • CSV로 내보내기: 재생 시각, 제목, 가수, 재생 시간(초), 가사 줄 수를 엑셀에서 열 수 있는 파일로 저장합니다. 전체 삭제 전에 보관용으로 쓰세요.

무엇을 어떻게 세나요

  • 들은 노래: 곡이 바뀔 때 한 곡으로 셉니다. 같은 곡을 처음부터 다시 틀면(절반 이상 들은 뒤) 한 번 더 셉니다.
  • 감상 시간: 멜론이 실제로 재생 중인 시간만 셉니다. 일시정지 중에는 늘지 않습니다.
  • 매칭된 가사: 오버레이에 표시된 가사 줄이 바뀐 횟수입니다.

11트레이와 창

  • 창의 X를 누르면 프로그램이 꺼지지 않고 알림 영역(트레이)으로 숨습니다. 오버레이는 계속 동작합니다.
  • 트레이 아이콘을 누르면 창이 다시 열립니다. 아이콘 메뉴에서 오버레이 표시, 고스트 모드, 멜론 창 되돌리기, 종료를 고를 수 있습니다.
  • 멜론 창 되돌리기는 멜론 창이 투명한 채로 남았을 때 누릅니다. 창을 바로 원래대로 돌리고, 다시 숨기지 않도록 고스트 모드에서 멜론 창 숨기기를 끕니다.
  • 완전히 끄려면 트레이 메뉴의 종료나 종료 단축키를 쓰세요. X로 바로 끄고 싶다면 설정 → 시스템 → 창을 닫으면 트레이로 최소화를 끕니다.
  • 이미 실행 중일 때 다시 실행하면 새로 뜨지 않고 기존 창이 앞으로 나옵니다.

12새 버전 업데이트

프로그램을 켜고 30초 뒤, 그리고 켜 둔 동안 하루에 한 번 GitHub에 최신 버전을 물어봅니다. 새 버전이 있으면 트레이 알림과 함께 대시보드 위쪽에 안내가 나타납니다. 정보 → 지금 확인으로 직접 확인했을 때는 그 자리의 업데이트 버튼으로도 진행할 수 있습니다.

  1. 업데이트를 누르면 변경 내용과 파일 크기가 표시됩니다.
  2. 지금 업데이트를 누르면 내려받습니다. 받는 동안에도 오버레이는 동작하고, 취소할 수 있습니다.
  3. 검증 후 교체받은 파일을 GitHub가 계산한 검증값(SHA-256)과 비교하고, 일치할 때만 프로그램을 닫았다가 새 버전으로 바꿔 다시 실행합니다.
  • 이 버전 건너뛰기를 누르면 그 버전은 자동으로 다시 알리지 않습니다. 정보 → 지금 확인으로는 언제든 확인할 수 있습니다.
  • 자동 확인은 정보 → 새 버전 자동 확인에서 끕니다. 확인할 때 GitHub에 전달되는 정보는 IP 주소와 프로그램 버전뿐입니다.
  • 교체 직전까지 원래 실행 파일은 그대로 두고, 이전 버전을 LyricsOverlay.exe.previous로 보관했다가 새 버전이 정상으로 시작하면 지웁니다. 새 버전이 시작되지 않으면 이 파일 이름을 LyricsOverlay.exe로 바꿔 되돌릴 수 있습니다.
  • 소스 코드로 실행 중이거나 프로그램 폴더에 쓸 수 없으면 릴리스 페이지를 열어 직접 받도록 안내합니다.

13데이터와 개인정보

감상 기록과 설정은 기본적으로 문서\LyricsOverlay 폴더에 저장됩니다. 감상 기록 파일은 PC 밖으로 보내지 않습니다. 외부로 보내는 요청은 가사 검색(지금 곡의 제목과 가수, 멜론 웹), 앨범 커버 이미지(멜론 이미지 서버), 예전 기록 커버 채우기(버튼을 눌렀을 때 예전 곡의 제목과 가수), 새 버전 확인(GitHub)입니다. 멜론으로 가는 요청은 설정 → 시스템 → 멜론 연동에서 끌 수 있고, 앱 이름을 밝혀 1초에 한 번 이하로 보내며 멜론이 거절하면 30분 동안 멈춥니다.

Lyrics Overlay는 MIT 라이선스로 공개된 비공식 도구이며 멜론과 제휴하지 않았습니다(멜론은 카카오엔터테인먼트의 상표). 프로그램에 포함된 오픈소스 구성요소와 글꼴의 라이선스는 정보 → 오픈소스 라이선스에서 볼 수 있습니다.

파일내용
lyrics_stats.json감상 기록과 누적 통계
overlay_settings.json오버레이 모양, 동작, 단축키, 가사 인식 영역
overlay_styles.json스타일 프리셋
window_restore.json고스트 모드로 바꾼 멜론 창의 원래 상태 (복구가 끝나면 지워짐). 데이터 폴더가 아니라 %LOCALAPPDATA%\LyricsOverlay에 둡니다
LyricsOverlay.log진단 로그: 앱이 한 일과 오류(곡 제목·가수 포함, 가사는 없음). %LOCALAPPDATA%\LyricsOverlay에 두며 최대 약 1.5MB까지만 남깁니다. 정보 → 진단 로그 남기기에서 끄거나(끄면 남은 로그도 지움) 폴더를 열 수 있고, 감상 기록 저장을 끄면 함께 멈춥니다
  • 경로 변경: 새 폴더에 지금 데이터를 저장합니다. 그 폴더에 이미 데이터가 있으면 덮어쓸지(기존 파일은 백업), 그 데이터를 쓸지(다시 시작 후 적용) 고릅니다. 이전 폴더의 파일은 지우지 않습니다.
  • 감상 기록 저장: 끄면 오버레이와 가사는 그대로 동작하고, 새 기록과 누적 감상 시간을 저장하지 않습니다. 대시보드의 "세션" 통계만 이번 실행 동안 셉니다.
  • Windows를 켤 때 자동 실행: 켜 두면 로그인할 때 창 없이 트레이로 시작해 오버레이를 띄웁니다. 현재 사용자 계정의 시작 프로그램에만 등록됩니다.
  • 앱 글꼴: 메뉴·설정·감상 기록 등 창의 글꼴을 Pretendard, 나눔스퀘어 네오, Wanted Sans 중에서 고릅니다. 누르면 바로 바뀝니다. 가사 오버레이 글꼴은 설정 → 외관에서 따로 정합니다.
  • 감상 기록은 암호화되지 않은 파일입니다. OneDrive의 문서 폴더 백업이 켜져 있으면 클라우드에도 동기화될 수 있으니, 원하지 않으면 경로를 OneDrive 밖으로 바꾸세요.

14문제 해결

가사가 표시되지 않거나 "가사를 기다리는 중…"에서 멈춰 있어요.
대시보드의 인식 상태를 먼저 보세요(4장). "영역을 벗어났어요"나 "글자를 찾지 못했어요"가 계속되면 가사 인식 영역을 다시 지정하세요(6장).
가사에 오타가 섞여 나와요.
원본 가사를 찾지 못하면 OCR로 읽은 글자를 그대로 보여 줍니다. 제목·가수가 같은 곡을 멜론 웹에서 찾지 못한 경우에도 엉뚱한 곡의 가사로 바꾸지 않고 OCR 결과를 씁니다. 인식 영역이 가사 두 줄에 딱 맞게 잡혀 있을수록 오타가 줄어듭니다.
멜론 창이 안 보여요.
고스트 모드에서 멜론 창을 숨기는 기본 동작입니다. F9로 고스트 모드를 끄거나 설정 → 동작 → 고스트 모드에서 멜론 창 숨기기를 끄면 다시 보입니다. 프로그램을 종료해도 원래대로 돌아옵니다. 그래도 안 보이면 트레이 아이콘 메뉴의 멜론 창 되돌리기를 누르세요(11장).
앨범 커버나 가사 보정이 한동안 동작하지 않아요.
멜론이 요청을 거절하면 30분, 10분 안에 세 번 실패하면 10분 동안 멜론에 요청하지 않습니다. 앱을 다시 켜도 그 시간은 이어집니다. 설정 → 시스템 → 멜론 연동에 남은 시간이 표시됩니다.
문제를 제보하고 싶어요.
정보 → 로그 폴더 열기로 LyricsOverlay.log를 찾아 GitHub Issues에 함께 올려 주세요. 곡 제목과 가수가 들어 있으니, 올리기 전에 내용을 한 번 확인하세요.
오버레이를 옮기거나 버튼을 누를 수 없어요.
클릭 통과가 켜져 있으면 클릭이 뒤로 넘어갑니다. 옮길 때는 위치·크기 조정을, 재생 버튼을 쓸 때는 F9로 클릭 통과를 끄세요.
창을 닫았는데 프로그램이 계속 실행돼요.
X를 누르면 트레이로 숨습니다(11장). 트레이 메뉴의 종료나 종료 단축키로 끄세요.
게임 중에 단축키가 먹지 않아요.
관리자 권한으로 실행된 게임 안에서는 일반 권한 프로그램의 단축키가 동작하지 않을 수 있습니다. LyricsOverlay도 관리자 권한으로 실행해 보세요.
재생 버튼이나 미디어 단축키가 멜론을 조작하지 않아요.
버튼과 단축키는 멜론 창에 직접 명령을 보냅니다. 멜론이 실행 중인지 확인하세요. 멜론 창을 찾지 못하면 Windows 미디어 키로 대신 보내는데, 이때는 다른 앱(브라우저 영상 등)이 먼저 반응할 수 있습니다. 대시보드 최근 활동에 "(미디어 키)"로 표시됩니다.
업데이트가 실패했어요.
지금 버전은 그대로 남습니다. 프로그램 폴더에 쓸 권한이 없거나 검증값이 맞지 않으면 설치하지 않습니다. 릴리스 페이지에서 직접 받을 수 있고, 교체 과정의 기록은 실행 파일 옆 LyricsOverlay.update.log에 남습니다.
실행할 때 보안 경고가 떠요.
코드 서명이 없는 개인 제작 프로그램이라 표시됩니다. GitHub 릴리스에서 내려받은 파일이 맞다면 추가 정보 → 실행을 누르세요. 릴리스의 LyricsOverlay.exe.sha256.txt와 PowerShell Get-FileHash 결과를 비교하면 파일이 바뀌지 않았는지 확인할 수 있습니다.
LyricsOverlay {{VERSION}} · 개인 학습 및 비상업적 용도로 제작한 비공식 도구이며, 멜론(카카오엔터테인먼트)과 관계가 없습니다.
화면의 곡 정보와 가사 문장은 예시입니다. 문의 및 버그 제보: github.com/Ow-wL/LyricsOverlay/issues
