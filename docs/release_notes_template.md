**업데이트 안내:** 1.2.0 이상이면 앱의 새 버전 알림에서 **업데이트**를 누르세요(정보 → 지금 확인 옆에도 버튼이 있습니다). 1.1.0 이하라면 아래 `LyricsOverlay.exe`를 직접 받아 기존 파일을 바꿔 주세요.

**개인정보:** 감상 기록 파일은 PC 밖으로 보내지 않습니다. 멜론 연동을 켜 두면 지금 듣는 곡의 제목과 가수가 멜론으로 전송되고, 앨범 커버는 데이터 폴더의 `covers`에 저장됩니다. 곡 하나당 데이터 사용량은 약 60KB입니다.

**파일 확인:** `LyricsOverlay.exe.sha256.txt`의 값과 PowerShell `Get-FileHash .\LyricsOverlay.exe -Algorithm SHA256` 결과가 같은지 비교하세요.

**요구 사항:** Windows 10 이상, 한국어 OCR 언어 기능, 멜론 PC 플레이어

**사용 가이드:** 첨부된 `LyricsOverlay_Guide_v{{VERSION}}.pdf` 또는 `.html` · 오픈소스 라이선스: `THIRD_PARTY_NOTICES.txt`
