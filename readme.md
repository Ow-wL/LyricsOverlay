# 🎵 LyricsOverlay

**LyricsOverlay**는 윈도우 환경에서 실행 중인 음악 플레이어(Melon, YouTube Music 등)의 가사를 실시간으로 인식하여, 예쁘고 스타일리시한 투명 오버레이로 화면에 띄워주는 **가사 전용 오버레이 도구**입니다.

윈도우 기본 OCR(광학 문자 인식) 엔진을 활용하여 높은 정확도와 가벼운 리소스로 작동하며, 사용자의 취향에 맞게 세밀한 커스터마이징이 가능한 직관적인 GUI를 제공합니다. 코딩, 게임, 웹 서핑 등 다른 작업을 하면서도 방해 없이 음악과 가사를 즐겨보세요!

---

## ✨ 주요 기능

- **실시간 가사 인식 및 자동 매칭**  
  텍스트로 가사를 출력하는 다양한 플레이어 화면을 인식합니다. OCR로 읽어들인 텍스트와 웹에서 검색된 완전한 가사 데이터를 실시간으로 비교하여, 현재 부르고 있는 정확한 구절을 찾아 매끄럽게 표시합니다.

- **재생 중인 곡 정보 표시**  
  가사 상단에 현재 재생 중인 음악의 **'제목'과 '가수' 정보**를 함께 띄울 수 있어 직관적인 음악 감상이 가능합니다.

- **강력한 전역 단축키 & 미디어 컨트롤**  
  오버레이 제어뿐만 아니라 **다음 곡(Ctrl+Shift+→), 이전 곡(Ctrl+Shift+←), 일시정지/재생(F8)** 등 미디어 제어 기능을 단축키로 지원하여 마우스 이동 없이 편리하게 조작할 수 있습니다.

- **아름답고 세련된 다크/라이트 모드 UI**  
  현대적이고 트렌디한 감각을 반영한 미니멀 디자인 툴입니다. 설정 탭이 **외관, 동작, 단축키, 시스템** 등 카테고리별로 나뉘어 있어 누구나 손쉽게 커스터마이징이 가능합니다.

- **커스텀 오버레이 & 프리셋 관리**  
  오버레이의 투명도, 아웃라인(외곽선) 굵기, 텍스트 색상, 글꼴 등을 자유롭게 조절할 수 있습니다. 자신이 만든 디자인은 '프리셋'으로 저장하고 나중에 다시 불러올 수 있습니다.

- **게임 및 작업 최적화 (고스트 모드)**  
  오버레이가 마우스 클릭을 투과하도록 설정(고스트 모드)하여, 화면 위를 클릭하더라도 뒤에 있는 창이 선택되므로 다른 작업을 할 때 전혀 방해를 주지 않습니다.

- **스마트한 감상 통계 대시보드**  
  내가 어떤 노래를, 어떤 가수를 가장 많이 들었는지 등 플레이 기록을 바탕으로 감상 통계를 분석하여 시각적인 데이터로 보여줍니다.

## 🚀 사용 방법

1. **설치 및 실행**  
   설치 후 `python main.py`를 실행하여 프로그램을 켭니다. (상세 설치 방법은 [`INSTALL.md`](./INSTALL.md)를 참고해 주세요)
2. **오버레이 활성화 및 설정**  
   앱이 실행되면 바탕화면에 투명한 가사 오버레이가 나타납니다. 설정 탭에서 위치, 크기, 폰트, 단축키 등을 취향에 맞게 조절하세요.
3. **음악 앱 실행**  
   음악 플레이어(예: 멜론)의 가사 창이 화면에 보이도록 띄워 둡니다.
4. **가사 감상**  
   LyricsOverlay 엔진이 백그라운드에서 가사 창을 읽어들여 투명 오버레이로 예쁘게 출력합니다.

## 📂 프로젝트 구조

- `main.py` : 애플리케이션 최상위 진입점 및 메인 루프
- `core/` : OCR 가사 인식, 단축키 매니저(`hotkey_manager.py`), 상태 및 통계 관리 등 핵심 로직
- `gui/` : 대시보드, 통계, 설정(카테고리 탭), 테마 등 사용자가 조작하는 메인 제어판 창
- `overlay/` : 가사 및 곡 정보를 화면에 그려주는 투명 오버레이 UI 요소 및 설정 매니저
- `lyrics/` : 웹 가사 검색 및 OCR 인식 텍스트 매칭(`matcher.py`) 로직
- `asset/` : 프로그램 구동에 필요한 아이콘 및 폰트 파일 등 리소스
