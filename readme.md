# 🎵 LyricsOverlay

**LyricsOverlay**는 윈도우 환경에서 실행 중인 음악의 가사를 실시간으로 인식하여, 예쁘고 스타일리시한 오버레이로 화면에 띄워주는 "가사 전용 오버레이 도구"입니다. 

윈도우 기본 OCR(광학 문자 인식) 엔진을 활용하여 높은 정확도와 가벼운 리소스로 텍스트를 인식하며, 사용자 취향에 맞게 모든 테마와 디자인을 커스터마이징할 수 있는 강력한 GUI를 제공합니다.

---

## ✨ 프로그램 주요 기능

- **실시간 가사 인식 (OCR)**  
  멜론(Melon), 유튜브 뮤직(YouTube Music) 등 텍스트로 가사를 출력하는 다양한 플레이어 화면을 인식하여 실시간으로 추적합니다.
- **자동 가사 매칭 알고리즘**  
  OCR로 읽어들인 텍스트 파편과 웹에서 검색된 완전한 가사 데이터를 비교/분석하여, 현재 부르고 있는 정확한 구절을 찾아내 매끄럽게 표시합니다.
- **아름답고 세련된 다크/라이트 모드 UI**  
  VS Code, Discord 등 현대적이고 트렌디한 디자인 감각을 반영한 미니멀 디자인 툴을 통해 직관적으로 설정을 제어할 수 있습니다.
- **커스텀 오버레이 & 프리셋 지원**  
  오버레이 투명도, 아웃라인(외곽선) 굵기, 색상, 글꼴 등을 자유롭게 변경할 수 있으며, 자신이 만든 디자인을 '프리셋'으로 저장하고 불러올 수 있습니다.
- **스마트한 감상 통계 (대시보드)**  
  내가 어떤 노래를, 어떤 가수를 가장 많이 들었는지 일간/주간/월간 단위로 차트와 함께 분석하여 시각적인 데이터로 보여줍니다.
- **게임 및 작업 최적화 (고스트 모드)**  
  오버레이가 마우스 클릭을 투과하도록 설정(고스트 모드)할 수 있어, 코딩이나 게임 등 다른 작업을 할 때 전혀 방해를 주지 않습니다.

## 🚀 사용 방법 안내

설치가 완료된 후 `python main.py`를 실행하여 프로그램을 켭니다. 
(설치 방법은 `INSTALL.md` 파일을 참고해 주세요.)

1. **메인 화면 & 오버레이 활성화**  
   앱이 켜지면 바탕화면 어딘가에 투명한 가사 오버레이가 나타납니다. 설정 탭에서 위치, 크기, 폰트를 마음대로 조절해 보세요.
2. **음악 앱 켜기 (예: 멜론)**  
   음악 플레이어의 가사 창이 화면에 보이도록 띄워 둡니다.
3. **즐기기!**  
   LyricsOverlay 엔진이 백그라운드에서 가사 창을 읽어들여 투명 오버레이로 예쁘게 출력합니다.

## 📂 프로젝트 구조

- `main.py`: 애플리케이션의 최상위 진입점
- `overlay/`: 가사 오버레이를 화면에 그려주는 핵심 UI 요소 및 설정 매니저
- `engine/` (로직 모음): OCR 가사 인식(`lyrics_matcher.py`) 및 웹 가사 검색 기능 처리
- `gui/`: 사용자가 조작하는 메인 제어판 창 (대시보드, 통계, 설정, 다크모드 테마 등 구현)
- `asset/`: 아이콘, 폰트 파일 및 스크린샷 이미지
